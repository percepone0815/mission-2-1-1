# mission 2-1-1
# 북클럽 메이트 프로젝트

## 프로젝트 소개

**독서클럽 운영자의 반복 업무를 돕는 '북클럽 메이트'를 설계하고, 모델
비교와 실제 대화를 통해 프롬프트를 개선한 프로젝트입니다.**

독서 미션 기획부터 참가자 안내, 북콘서트 운영 지원, 후기 분석까지
독서클럽 운영 과정에서 반복되는 업무를 AI가 지원하도록 설계했습니다.

## 1. 과업을 선택한 이유

독서클럽 운영에서는 매달 독서 미션을 만들고, 일정 변경을 반영하고,
공지문과 설문을 작성하는 일이 반복됩니다. 이러한 업무를 AI가 지원하도록
하되, **책에 없는 내용이나 아직 확정되지 않은 일정을 임의로 만들어내지
않도록 하는 것**을 중요하게 생각했습니다.

## 2. 모델 비교 및 선정

ChatGPT·Gemini·Claude의 무료 서비스를 비교했습니다. 다음 기준을 중심으로
결과를 살펴봤습니다.

-   정보 파악
-   목차 반영
-   활동의 구체성
-   운영 편의성
-   공지문 가독성

비교 보고서에서는 **필요한 정보를 세밀하게 묻고, 책의 흐름과 운영자가
확인할 사항을 잘 반영한 Claude를 선정**했습니다.

이는 모든 업무에서 Claude가 가장 우수하다는 의미가 아니라, 이번 독서클럽
운영 과업에 더 적합하다고 판단했다는 의미입니다.

## 3. AI의 역할과 핵심 규칙

AI에게 **'북클럽 메이트'라는 독서클럽 운영 매니저 역할**을 부여하고,
친근하면서도 정확하게 답변하도록 설계했습니다.

핵심 규칙은 다음과 같습니다.

-   제공되지 않은 책 내용이나 일정을 만들어내지 않기
-   기존 조건 중 유지할 것과 변경할 것을 구분하기
-   참가자의 실제 후기와 AI의 개선 제안을 구분하기
-   필요한 정보가 부족하면 먼저 질문하기

## 4. 실제 실험 내용

다섯 가지 업무 상황을 설정해 대화하며, 프롬프트가 운영 조건을 얼마나 잘
반영하는지 확인했습니다.

  실험 상황            확인하려 한 점
  -------------------- -------------------------------------------
  활동량 줄이기        시간과 활동 개수 제한을 지키는지
  북콘서트 일정 변경   다른 주차의 기존 조건을 유지하는지
  후기 설문 설계       필요한 질문과 개인정보 보호를 고려하는지
  가상 후기 분석       일부 의견을 전체 의견으로 확대하지 않는지
  최종 운영안 작성     앞서 정한 조건을 종합해 반영하는지

위 실험을 통해 활동량 조정, 일정 변경, 설문 구성, 가상 후기 분석, 최종안
작성을 수행했습니다.

## 5. 프롬프트 개선 과정

처음에는 역할과 조건만 제시하는 **Zero-shot** 방식으로 요청했습니다.

이후 활동량 조정·일정 변경·되묻기 예시를 제공하는 **Few-shot** 방식과,
다음 절차를 함께 적용했습니다.

1.  조건 확인
2.  결과 작성
3.  최종 점검

그 결과 기록에서는 생각 질문과 후기 양식의 연결, 항목별 작성 예시가 더
구체화됐습니다.

다만 여러 지시를 함께 추가했으므로, 이러한 개선을 **Few-shot만의
효과라고 단정하지 않았습니다.**

## 6. 배운 점과 남은 검증 과제

이번 프로젝트에서 확인한 핵심은 **AI가 초안을 잘 만드는 것과 실제 업무에
바로 사용할 수 있는 것은 다르다**는 점입니다.

실제 운영에 적용하기 전 다음 사항을 추가로 확인할 필요가 있습니다.

-   책 본문과 결과물의 내용 대조
-   실제 설문 작성에 걸리는 시간 확인
-   개선된 프롬프트의 추가 검증

또한 v1·v2는 초기 설계와 개선안을 정리한 버전입니다. 별도 시스템
설정에서 전후 성능을 비교한 실험으로 설명하지 않는 것이 정확합니다.

## 7. 프로젝트를 마무리하며

> 이번 프로젝트는 AI가 독서클럽 운영을 완전히 대신하도록 만드는 것이
> 아니라, **기존 조건을 유지하며 운영자의 의사결정을 돕도록 설계한
> 실습**입니다.
>
> 역할만 주는 데서 그치지 않고 예시와 점검 규칙을 추가해 결과를
> 구체화했으며, 확인하지 못한 부분은 완료했다고 하지 않고 추가 검증
> 사항으로 남겼습니다.
